# Visualization Workflow

Use for charts and visual summaries. Consult the live chart tool description
for supported chart types and configuration fields.

1. Identify the question: trend, comparison, composition, or distribution.
2. Read the source values and formulas. Confirm units, labels, missing values,
   and category ordering before chart creation.
3. Choose the simplest supported chart that answers the question.
4. Configure title and placement separately where the tool requires it.
   Keep the chart near the report, without covering important source cells.
5. Re-read the source and chart listing to check type, name, and placement.
   A chart listing is not a rendered visual preview; do not claim otherwise.

Use explicit metric/time-period titles, limit categories, and avoid misleading
comparisons between incompatible units. Aggregate only with a clear meaning.
Check the chart source again after data updates.
