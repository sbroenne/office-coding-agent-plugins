# Reporting Workflow

Use for summaries, KPI blocks, rollups, and report-ready worksheet outputs.
The live tool descriptions define the available table, pivot, and formatting actions.

1. Discover and read the source, including headers and complete row coverage.
2. Decide whether a table, pivot, or formula section best answers the question.
   Keep source data separate from reporting outputs.
3. Use exact source header names for pivot fields. Check destination space
   before creating a report so existing content is not overwritten.
4. Format currency, percentages, dates, and counts according to their meaning.
   State denominators and time periods for KPIs.
5. Refresh/recalculate where needed and reconcile totals with the source.

Use clear labels and a small number of high-signal metrics. Do not silently
change aggregation meaning: a sum, average, distinct count, and percentage
answer different questions. Re-read the report and inspect pivot structure
before presenting findings.
